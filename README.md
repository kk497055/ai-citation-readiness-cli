# AI Citation Readiness CLI

A free, private five-signal check for website clarity, evidence, consistency, and crawlability.

Run it without installing:

```bash
npx ai-citation-readiness
```

The audit asks five yes/no questions, calculates a directional score, and prints the three highest-priority fixes. No website data is collected or transmitted.
